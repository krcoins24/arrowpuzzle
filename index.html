4. Local Data Storage Architecture (Android SharedPreferences)

To preserve your puzzle completion milestones and audio preferences across gameplay sessions, the Game utilizes Android's native, sandboxed key-value storage engine known as SharedPreferences.

4.1 What Exact Game Data Is Stored Locally?

All stored values are strictly gameplay-related, non-personal, and entirely localized to your physical device. The following parameters are maintained:

  • saved_level (Integer): Remembers the highest level number unlocked by the player (e.g., Level 1, Level 20).
  • stars_level_{X} (Integer): Records the star score (1, 2, or 3 stars) achieved upon solving each puzzle level.
  • sound_enabled (Boolean): Remembers your toggle preference for in-game sound effects (tap sounds, win chime, error buzzer).
  • music_enabled (Boolean): Remembers your toggle preference for calming background musical themes.
  • haptic_enabled (Boolean): Remembers your toggle preference for gentle haptic vibration feedback on puzzle taps.
  • theme_mode (String): Stores your visual theme preference for the user interface.

4.2 Where Is This Data Stored & Who Has Access?

This data is written exclusively to an internal XML file located in the Game's private, operating-system-sandboxed directory on your device: /data/data/com.choco.animation.arrow/shared_prefs/game_prefs.xml.

Under Android's security isolation architecture, no other application or third-party service can inspect, read, or alter this sandboxed file. Furthermore, the Game has no cloud sync, no remote database, and no server connectivity. Your level progress never leaves your physical phone or tablet.

4.3 How Can You Erase or Reset Your Game Progress?

Players maintain full control over their local gameplay records at all times:

  • In-Game Progress Reset: Open Settings within the Game and tap "Reset Progress". Confirming the reset will immediately restore your progress to Level 1.
  • Device Settings Clear: Open your Android device Settings > Apps > [Game] > Storage > Clear Storage / Clear Data to immediately wipe all local preferences.
  • Uninstalling the Game: Removing the Game permanently and irreversibly deletes the entire private storage folder and all associated progress from your device.

9. Security Architecture & Code Hardening

To safeguard the Game and ensure an uncompromising level of integrity, the Game's code has been hardened prior to release:

  • ProGuard / R8 Obfuscation: The release binary is protected with aggressive code shrinking and repackaging rules, stripping source file names and variable tables to prevent decompilation and tampering.
  • No Cleartext Traffic: All external web interactions strictly utilize encrypted HTTPS/TLS protocols.
  • Protected Activity Components: Internal game activities are set to android:exported="false" to protect against unauthorized inter-app communication from malicious applications.
